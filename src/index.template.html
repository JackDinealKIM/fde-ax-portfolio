03 · Packages

외주 패키지 3종

작게 시작해서 숫자가 나오면 넓힙니다. 모든 패키지는 3일 MVP로 먼저 동작을 확인하고, 그 다음에 본 구축으로 넘어갑니다.

Entry · 검증용

진입형 — 사내 AI 지식베이스

150~250만원 / 1주

“AI가 우리 회사 문서를 제대로 읽는지” 먼저 확인하고 싶은 팀

  • 문서 300청크 이내 RAG 구축 (PDF·DOCX·시트)
  • 출처 인용 답변 + 환각 방지(근거 없음 응답)
  • 질문 20개 골든셋으로 정확도 리포트
  • 웹 UI 1개 · 계정 5개
Core · 주력

주력형 — 반복 업무 자동화

350~600만원 / 2~3주

ERP·메신저까지 묶어 실제 업무 흐름을 줄이고 싶은 회사

  • ERP(DB)·메신저 로그·문서 3개 소스 통합 검색
  • 업무 에이전트 2~3개 (재고 알림·CS 초안·정산 점검)
  • Ragas 자동 평가 + GitHub Actions 회귀 테스트
  • 권한 분리 · 감사 로그 · 운영 대시보드
  • 인수인계 문서 + 담당자 교육 2시간
Enterprise · 보안

고단가형 — 폐쇄망 보안 구축

800만~원 / 4주+

외부 API 반출이 안 되는 제조·금융·공공 협력사

  • 인터넷 차단 환경 Docker · k3s 클러스터 배포
  • Ollama 로컬 LLM (EXAONE·Llama 계열) 튜닝
  • 오프라인 이미지 번들 · 무결성 검증 스크립트
  • HA 구성 · 백업·복구 리허설 · 장애 대응 런북

부가세 별도 · 서버·API 비용은 실비 정산 · 범위가 명확하면 3일 내 견적 확정

04 · Process

진행 프로세스 4단계

첫 미팅에서 계약까지 길게 끌지 않습니다. 진단 → 3일 MVP → 구축 → 인수인계, 각 단계마다 손에 잡히는 산출물이 남습니다.

STEP 01
D+0 · 1~2일

업무 진단 (Discovery)

현장 담당자 인터뷰와 업무 로그로 병목을 특정합니다. “어디가 느린지”를 추측하지 않고 시간으로 잽니다.

산출물병목 진단서 · 인터뷰 10문항 · 후보 시나리오 3개
STEP 02
D+3 · 3일

3일 MVP 검증

실데이터 일부로 돌아가는 프로토타입을 만들어 대표와 실무자가 직접 눌러보게 합니다. 판단은 여기서 끝냅니다.

산출물동작하는 데모 URL · 질문 20개 정확도 리포트
STEP 03
2~4주

구축 · 배포

권한·감사 로그를 붙여 운영 가능한 형태로 만듭니다. 요구가 바뀌면 범위를 문서로 다시 고정합니다.

산출물클라우드 또는 폐쇄망(Docker·k3s) 배포 · 모니터링
STEP 04
마지막 3일

검수 · 인수인계

체크리스트로 함께 검수하고, 담당자가 혼자 운영할 수 있게 넘깁니다. 인수인계 없는 납품은 하지 않습니다.

산출물검수 체크리스트 · 운영 런북 · 담당자 교육
05 · Proof

품질도 숫자로 검증합니다

“잘 된다”는 말 대신, Ragas로 채점한 지표를 CI에 걸어 회귀를 막습니다. 아래는 데모 데이터셋 기준 예시 수치입니다.

Ragas 평가 (골든셋 40문항)

Faithfulness가 1.0 미만이면 배포를 막는 게이트를 둡니다.

Faithfulness
근거 없는 문장 비율0.96
Answer relevancy0.92
Context precision0.89
Context recall0.87

※ 데모용 예시 수치입니다. 실제 프로젝트에서는 고객 데이터로 골든셋을 만들고 측정합니다.

구성 스택

무료·오픈소스 우선. 고객사 보안 정책에 따라 교체 가능합니다.

업무 진단 → 3일 MVP → 구축 → 인수인계. 지금 반복하고 있는 업무 하나만 알려주시면, 그 업무가 몇 시간으로 줄어드는지 계산해서 회신드립니다.
